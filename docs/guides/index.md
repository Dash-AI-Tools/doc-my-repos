# Guides

Step-by-step pages for the things you do with DocMyRepos.

- [Getting started](./getting-started.md): run it with Docker, or develop on the host.
- [Comments](./comments.md): discussing a document on its page, who can do what, limits and moderation.
- [Ask the docs](./ask.md): the AI assistant: setting up the provider and model, what is sent, limits and privacy.
- [Configuration](./configuration.md): `docmyrepos.config.yml`, environment variables, limits and the scheduler.
- [Webhooks](./webhooks.md): which GitHub events are handled and how deliveries are processed.
- [Search](./search.md): query syntax, ranking, filters and the command palette.
- [OKF support](./okf-support.md): how Open Knowledge Format repositories are detected and shown.

Registering the GitHub App has its own page: [GitHub App setup](../github-app-setup.md).
